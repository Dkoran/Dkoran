## About Me

I am a Senior Mobile Engineer based in Accra, Ghana with 8+ years of experience designing, building and maintaining production-grade Android applications.

My engineering focus includes:

- Modern Android development with Kotlin and Jetpack Compose
- Kotlin Multiplatform (KMP) and Compose Multiplatform (CMP)
- Clean Architecture, MVVM, MVI and modular architecture
- Fintech and mobile money platforms
- Enterprise-grade Android applications
- App scalability, maintainability and performance optimization
- CI/CD automation, testing and production stability
- AI-assisted engineering workflows using Claude and GitHub Copilot

I enjoy building reliable mobile products with clean code, reusable architecture and modern user experiences.
